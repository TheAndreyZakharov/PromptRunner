# PromptRunner

Лёгкое desktop-приложение для воспроизводимого black-box-тестирования пользовательского AI-чата через экран, координаты мыши, клавиатуру и буфер обмена.

## Что уже реализовано

- чтение структуры IT-Interview-Question-Bank с рабочей очередью из `Questions_with_AI_Answers_By_Topic_*`;
- поиск последнего заполненного ответа и автоматический видимый следующий ID;
- чтение `Questions_By_Topic_*` только для контекста текущей подтемы;
- фильтрация по активному языку RU/EN и allowlist;
- естественная числовая последовательность ID с продолжением с первого незакрытого вопроса;
- формирование промпта из tools/answer-generation-prompt.md, контекста текущей подтемы и текущего вопроса;
- атомарная запись скопированного Markdown-блока в правильный файл ответов;
- координатное управление мышью и клавиатурой через Rust;
- плавное движение курсора с конечной точкой внутри зоны;
- отдельные action-зоны и observation-зона для шаблонов writing/busy, send и no_prompt;
- после клика отправки курсор плавно уходит из observation-зоны в безопасную точку перед проверкой состояния;
- пауза, продолжение, остановка, лимит вопросов на сессию и новый чат через заданное число вопросов;
- прогресс с тремя барами и процентами: весь банк, текущий большой пункт и текущий подпункт;
- компактный прокручиваемый лог: новые события сверху, максимум 1000 записей;
- пользовательские профили: готовых профилей нет, пользователь калибрует и сам сохраняет раскладку;
- выбор монитора и разметка зон в обычном окне PromptRunner по снимку всего выбранного экрана;
- прокрутка снимка и масштаб 10–500% через список, ⌘/Ctrl +/−, ⌘/Ctrl+0 и колесо с модификатором;
- сохранение writing/busy, send и no_prompt-шаблонов непосредственно из текущей observation-зоны;
- системная, светлая и тёмная тема;
- Rust unit-тесты и smoke-тест на реальном банке.

## Запуск в режиме разработки

    npm install
    npm run dev:app

Rust-кэш dev-сборки хранится вне репозитория и сохраняется между запусками. Перед запуском, если он становится больше 2 ГБ, PromptRunner автоматически удаляет только старый временный `incremental`-кэш; текущий бинарник и собранные зависимости сохраняются. После запуска кэш не очищается и активную сессию не прерывает. Профили, путь к банку и прогресс хранятся отдельно в системном каталоге PromptRunner и не удаляются.

`npm run build` собирает только фронтенд в `dist/` и намеренно не создаёт установочные приложения.

## Релизная упаковка для macOS и Windows

Для создания нативных приложений используйте отдельную команду:

    npm run package:all

Она выполняется на macOS и кладёт в папку `release/` три результата:

- `PromptRunner.app` — приложение для macOS;
- `PromptRunner-windows-x64-setup.exe` — Windows NSIS-инсталлятор;
- `SHA256SUMS` — SHA-256 исполняемого файла внутри `.app` и Windows-инсталлятора.

Windows `.exe` не пытается собираться на Mac: скрипт запускает `.github/workflows/package-windows.yml` на Windows GitHub runner, ждёт окончания и скачивает готовый инсталлятор в ту же папку. Поэтому перед запуском нужно закоммитить и отправить текущую ветку в GitHub, а также один раз авторизовать GitHub CLI командой `gh auth login`. Рабочее дерево должно быть чистым — это гарантирует, что `.app` и `.exe` собраны из одного коммита.

## Первый запуск

1. Укажите путь к репозиторию банка вопросов — PromptRunner запомнит его в настройках и подставит при следующем запуске.
2. Выберите разрешённые языки и активный язык.
3. Откройте калибровку, выберите нужный монитор и перетащите мини-зоны из верхней панели на чистый снимок экрана; каждую сторону и угол можно изменить отдельно.
4. Для generation_state PromptRunner автоматически подставит найденные в assets/ шаблоны `writing`, `send` и `no_prompt`; при необходимости их можно заменить или переснять кнопками writing/busy, send и no_prompt.
5. Введите имя профиля и нажмите «Сохранить» — разметка и профиль сохранятся на диске; повторная калибровка обновит выбранный профиль.
6. Сначала используйте «Проверочный прогон без кликов», затем отключите его для рабочего теста.

Операционная система может запросить разрешения на управление указателем, клавиатурой и запись экрана. PromptRunner не использует DOM, Accessibility-дерево, внутренний API или поиск элементов тестируемого чата.
